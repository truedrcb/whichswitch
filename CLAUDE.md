# whichswitch

Индикатор раскладки клавиатуры для Windows. Показывает текущий язык (RU/EN)
в заголовке и иконке окна в панели задач; при включённом показе панели задач
на всех мониторах виден везде.

## Принципы
- Только событийная схема, без поллинга и без таймеров в фоне.
- Без глобальных хуков клавиатуры (WH_KEYBOARD_LL): утилита не должна видеть нажатия.
- Без сети, без сторонних зависимостей, код короткий и читаемый (важна проверяемость).
- Механизм: RegisterShellHookWindow + HSHELL_LANGUAGE / HSHELL_WINDOWACTIVATED.

## Статус
- Код v1 собирается и работает (проверено на Win11, 3 раскладки).
- Находки: HSHELL_LANGUAGE = 8 (не 0x19); на Win11 при смене раскладки приходит
  недокументированный код 0x38. Сообщение приходит РАНЬШЕ, чем раскладка потока
  реально меняется, поэтому читаем её через разовый таймер (сейчас 400 мс, 80 мс не хватало).
- Нужно проверить: подобрать минимальную надёжную задержку (или TSF-уведомления вместо
  таймера); обновляется ли иконка свёрнутого окна; несколько мониторов.
- Запасной вариант, если HSHELL_LANGUAGE не приходит: SetWinEventHook
  на смену фокуса + однократная проверка раскладки.
